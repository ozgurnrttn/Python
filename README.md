# Python Alıştırmaları

Python öğrenirken yazdığım küçük programlar: konsol uygulamaları, basit oyunlar ve iki grafik
uygulama. Hepsi yalnızca standart kütüphaneyi kullanır, ek kurulum gerekmez.

## Programlar

| Dosya | Ne yapar |
|---|---|
| `gorsel-basit-hesap-makinesi.py` | Tkinter ile grafik arayüzlü hesap makinesi |
| `hesap-makinesi-2.py` | İki sayı üzerinde dört işlem, mod, yüzde, üs ve kök alma; işlem geçmişi tutar |
| `XOX.py` | Bilgisayara karşı XOX (tic-tac-toe); bilgisayar olası hamleleri oyun ağacı üzerinden değerlendirir |
| `Tas-Kagit-Makas.py` | Bilgisayara karşı taş kağıt makas |
| `sayisal-loto.py` | İstenen sayıda rastgele sayısal loto kolonu üretir |
| `siralama.py` | Seçmeli sıralama (selection sort) ve kabarcık sıralaması (bubble sort) |
| `taban-islemleri.py` | Tam sayıları 2 ile 10 arasındaki tabanlar arasında dönüştürür |
| `sicaklik.py` | Celsius, Réaumur, Fahrenheit ve Kelvin arasında sıcaklık dönüşümü |
| `element.py` | Girilen molekül formülünün (örn. `C6 H12 O6`) mol kütlesini hesaplar |
| `Sinh.py` | sinh(x) değerini seri açılımıyla N terime kadar hesaplar |
| `hexagon.py` | Turtle ile renkli spiral çizer |

## Çalıştırma

Python 3 yeterli:

```bash
python XOX.py
```

`gorsel-basit-hesap-makinesi.py` ve `hexagon.py` pencere açar (Tkinter gerekir; Windows ve macOS
kurulumlarında hazır gelir).
